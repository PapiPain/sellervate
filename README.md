# Sellervate CX Hub — Control de Calidad, Onboarding & Demostración de Servicio

Plataforma de ingeniería para la gestión de calidad de experiencia del cliente (CX) multi-inquilino (*VoltScooters*, *EcoPack Solutions*, *Nordic Glow*). Diseñada para sustituir la auditoría informal en Slack por un sistema de registro auditable, una biblioteca pedagógica de onboarding y paneles de evidencia cuantitativa para marcas corporativas.
